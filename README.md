# Relatos Burger

Site da hamburgueria Relatos Burger.

- `backend/`: API Java + Spring Boot + MySQL
- `frontend/`: Flutter Web
- `docs/`: documentação da equipe

## Rodando o backend
1. Crie o banco e o usuário no MySQL (ver docs/ambiente.md)
2. Defina a variável de ambiente `DB_PASSWORD`
3. Rode `RelatosBurgerApplication` pelo IntelliJ
